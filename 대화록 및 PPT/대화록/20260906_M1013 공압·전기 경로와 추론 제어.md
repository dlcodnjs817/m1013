## 0. 결론

```
공기  팔 내부 통과 불가.  외부 호스가 유일한 방법.          ← M1013 구조상 제약
전기  팔 내부로 이미 들어옴.  플랜지 DO 6채널 사용 가능.     ← 제어에 문제 없음

→ 그리퍼 사용 가능.  추론 중 제어 가능.
→ 다만 래퍼 소프트웨어 3종이 아직 미착수 (§4).
```

밸브를 전완이 아니라 **툴단(그리퍼 측면)** 에 올린 설계 결정이 이 구조에서 나왔다.
공기는 밖에서, 전기는 플랜지에서 오게 해서 **툴 끝에서 만나게** 한 것이다.

---

## 1. M1013 은 팔 내부 공압 배관이 없다

두산 설치매뉴얼 v1.7 원본으로 확인. 근거 3가지.

### 1.1 툴 플랜지에 공압 포트가 없다

p.36 `Tool output flange, ISO 9409-1-50-4-M6` 도면에 있는 것 전부:

```
4-M6 TAP DP6          툴 체결
Ø6 (H7) REAMER DP6    위치결정 핀홀
Ø63 (h7)              착좌 보스
Ø31.5 (H7)            센터링 보어
X1 · X2               M8 8핀 커넥터 — IN 3ch / OUT 3ch, DC24V 최대 3A
```

**공기가 나오는 구멍이 하나도 없다.**

### 1.2 중앙 Ø31.5 는 막힌 구멍이다

측면도를 700 DPI 로 확대해 확인한 결과, Ø31.5 보어는 **깊이 6.4 mm 에서 바닥이 보이고
그 아래는 통짜**다. 관통이 아니라 센터링용 얕은 자리다.

```
플랜지 면 기준
   0.90 mm   C1 모따기 바닥
   6.42 mm   ★ 보어 바닥  ← 여기서 끝. 아래로 뚫려 있지 않다
```

튜브를 꽂아 넣을 구멍이 아니다.

### 1.3 매뉴얼 125쪽 전체에 공압 언급이 1번뿐

`pneumatic|air line|air hose|air supply|compressed air|tubing|hose` 정규식 전수 검색 결과
**p.49 한 곳**만 걸렸고, 내용은 "외부 솔레노이드 밸브·릴레이·PLC 를 I/O 로 제어할 수 있다"는
맥락이다. **내장 배관 항목 자체가 존재하지 않는다.**

## 2. TX2-90 과의 차이

```
TX2-90 (Stäubli 산업용)   베이스 ──[ 팔 내부 공압 라인 ]── 전완 ── 툴
                          "user lines already installed" 옵션
                          솔레노이드 밸브 내장 옵션까지 있음

M1013 (두산 협동로봇)      베이스 ──[      없음       ]── 툴
                          호스를 팔 표면에 클립·스파이럴로 고정해 내림
```

TX90 리그에서 호스가 팔 안으로 들어가는 것은 **Stäubli 의 기능**이고,
M1013 으로 넘어오면서 그 이점이 사라졌다. 이것이 밸브 위치를 재검토한 직접적 이유다.

> 09-03 정정 이력에 `밸브 위치 | "TX90 은 툴단" | **전완 브래킷** | 사진` 항목이 있다.
> TX90 에서 밸브는 툴단이 아니라 **전완**에 있었다. 내장 에어가 J6 까지 왔으므로 그래도 됐다.

---

## 3. 그래서 어떻게 쓰는가 — 경로 분리

```
[공기]  콤프 PL-10ST ─ 레귤레이터 AW20 ─┐
                                        │  코일호스 15 m (팔 바깥)
                                        ▼
                                 툴단 SY5120 밸브 ─ 스피드컨트롤러 ×2 ─ 그리퍼

[전기]  컨트롤러 ─[ 팔 내부 배선 ]─ 플랜지 X1/X2 ─ M8 8핀 케이블 ─ SY5120 솔레노이드
                                                                └ D-M9N 오토스위치 ×2
```

**밸브를 툴단에 둘 때의 이득**

| | |
|---|---|
| 손목 통과 호스 | 2가닥(A·B) → **1가닥(공급만)** — J6 회전 시 꼬임 감소 |
| 응답 속도 | 밸브~그리퍼 거리가 짧아져 개폐 지연이 줄어듦 |
| 전기 배선 | 플랜지 I/O 가 바로 옆이라 케이블이 짧음 |

호스 마지막 구간을 **J6 축과 동축**으로 정렬하면 회전이 "감김"이 아니라 "비틀림"이 된다.
J6 실사용 가동폭은 159 에피소드 전수 실측 기준 **81.8°** (사양 ±360° 의 11%) 라
여유 루프로 충분히 흡수된다.

## 4. 추론 시 제어 경로

```
정책 (ACT / SmolVLA)
  └─ 그리퍼 출력 (이진: 열림 / 닫힘)
       └─ dsr_driver 래퍼 (ROS2)          ← 미착수
            └─ 플랜지 DO 1채널 ─ M8 케이블 ─▶ SY5120 솔레노이드
                                              └─ 공기 방향 전환 → 그리퍼 개폐
       ◀── 플랜지 DI 2채널 ◀── D-M9N 오토스위치 ×2 (열림·닫힘 실측)
```

### 4.1 자원은 충분하다

| 자원 | 필요 | 보유 | |
|---|---|---|---|
| DO (밸브 구동) | 1 | 6 (X1·X2 각 3ch) | ✅ |
| DI (오토스위치) | 2 | 6 | ✅ |
| 전류 — 유지 | 4.2 mA (Z 절전회로) | 채널당 50 mA | ✅ 여유 92% |
| 전류 — 돌입 | ≈ 42 mA (1.0 W, 초기 ~60 ms) | 채널당 50 mA | ⚠️ 여유 16% |

> 매뉴얼이 "전류 제한 없음 — 초과 시 영구 손상" 이라 경고한 포트다.
> 불안하면 DO 로 소형 릴레이/MOSFET 을 구동하고 밸브는 별도 24 V 에서 먹인다.

### 4.2 배관 방향 — 안전 기준

```
밸브 A → 그리퍼 「S」 (닫힘)
밸브 B → 그리퍼 「O」 (열림)
```

**반대로 걸지 말 것.** 정전·비상정지 시 그리퍼가 **열려서 큐브를 놓아야** 안전하다.

## 5. 미착수 — 추론 전에 만들어야 할 것 3가지

09-03 §12 에도 `dsr_driver 래퍼 · 히스테리시스 · grip-lead | 미착수` 로 기록돼 있다.

### 5.1 채터링 방지 (히스테리시스)

```
정책 명령 주기      30 Hz  (초당 30회)
MHF2 최대 동작      60 c.p.m. = 초당 1회
```

정책 출력이 0.49 ↔ 0.51 사이에서 떨리면 밸브가 초당 수십 번 딸깍거린다. **그리퍼가 상한다.**

→ 히스테리시스(예: 닫힘 ≥ 0.6 / 열림 ≤ 0.4) + **최소 유지시간** 을 래퍼에 넣는다.

### 5.2 `--grip-lead` (선행 명령)

공압은 전기보다 느리다. DO 를 켜도 조가 실제로 닫히기까지 지연이 있다.

```
D-M9N 오토스위치 2개로 열림·닫힘 지연을 각각 실측
→ 30 Hz 기준 1.5 ~ 3 프레임 정도 명령을 앞당겨 보냄
```

**벤치 배관만 되면 바로 잴 수 있다.** 부품 도착 후 발주 대기와 병렬로 진행 가능.

### 5.3 관측값 정의

정책 입력의 그리퍼 상태가 **명령값**인지 **실제값(오토스위치)** 인지 맞춰야 한다.
v5 학습 데이터의 그리퍼 채널이 명령값이라면 명령값을 에코해 주는 편이 정합적이다.
→ v5 채널 정의 확인 후 결정.

## 6. 부수 확인 — 어댑터 Ø20 관통의 용도 서술 정정

09-03 설계서는 어댑터 중앙 Ø20 관통을 이렇게 설명했다.

> "Ø20 관통 — 튜브·배선 통로" · "호스 마지막 구간을 J6 축과 동축 정렬 → 어댑터 Ø20 보어 활용"

그런데 §1.2 에서 확인했듯 **플랜지 중앙이 막혀 있다.** 로봇 쪽으로는 갈 데가 없고,
반대쪽은 그리퍼 배면이 막고 있다. **"통로" 라는 설명은 실제로 성립하지 않는다.**

| | |
|---|---|
| 설계 문제인가 | ❌ **아니다.** 구멍이 하나 더 있는 것뿐이라 간섭·강도 문제 없음 (13.6 g 경량화) |
| 조치 | 발주 변경 불필요. **문서 서술만 정정** |

호스는 팔 바깥을 타고 내려와 그리퍼 옆 밸브로 바로 들어간다. Ø20 은 여유 공간으로 남는다.

## 7. 벤치에서 확인할 것

| | 항목 | 방법 |
|---|---|---|
| 1 | 콤프 최대압력 0.7 MPa 도달 | 게이지 |
| 2 | SY5120 커넥터 극성 | Z 타입은 극성 있음 (적 +24 V / 흑 0 V) |
| 3 | 배관 방향 A→S / B→O | 육안 + 통전 시험 |
| 4 | **개폐 지연 양방향 실측** | D-M9N 2개 → `--grip-lead` 값 산출 |
| 5 | 압력 튜닝 | 0.1 MPa 부터 올려가며 최소 파지압 탐색 |
| 6 | 스피드컨트롤러 조절 | 조가 큐브를 쳐내지 않는 속도까지 조임 |

**①~③ 은 로봇 없이도 가능하다.** 부품만 도착하면 어댑터 가공을 기다리는 동안 끝낼 수 있다.
