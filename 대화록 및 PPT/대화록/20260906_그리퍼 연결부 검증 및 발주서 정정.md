### 2.1 볼트가 왜 전부 틀렸나

같은 구조의 실수가 3번 반복됐다.

```
판 두께 T, 카운터보어 깊이 C, 볼트 길이 L, 상대 탭 깊이 D 일 때
   나사 물림 E = L − (T − C)
   조건 ①  E < D        (바닥 안 침)
   조건 ②  C ≥ 머리 높이 (머리 잠김)

M6: T=12, C=6.5, L=12, D=6  →  E=6.5 > 6  ❌   와셔 넣으면 E=5.5 ✅ 이지만 머리 7.0 > 6.5 ❌
M4: T=8,  C=4.5, L=8,  D=4  →  E=4.5 > 4  ❌
M3: T=4,  C=0,   L=8,  D=3.5→  E=4.0 > 3.5 ❌
```

**두 조건이 동시에 성립하는지 확인하지 않았다.** M6 는 특히 와셔로 ①을 고치면서 ②를 깨뜨렸다.


### 4.6 클로킹 — 4가지 → **2가지로 좁혀짐**

`replay_isaac.py:157` 확인:

```python
pj.CreateAxisAttr("X")                            # 조 이동축 = 플랜지 로컬 X
fj.CreateLocalPos1Attr(Gf.Vec3f(0, 0, -0.035))    # 회전 없이 link_6 에 고정
```

조 이동 방향이 플랜지 로컬 X 로 고정 → 장축이 Y 를 향하는 2가지는 탈락.

> 다만 이 축 설정이 데이터에서 온 것인지 모델링 선택인지는 **URDF 의 link_6 프레임과 대조 필요.**
> 확정 전이라도 핀홀 하도를 4곳 다 뚫어두면 어느 경우든 대응된다(§5.2).

### 4.7 압착량 상한은 1.5 mm 로 묶여 있다 (09-03 서술 완화)

09-03 문서는 "하드 스톱이 없다 · 큐브가 유일한 스톱 · 실린더 힘이 그대로 폼에 들어간다" 고 적었다.
**좌우 조끼리 안 닿는다**는 뜻으로는 맞지만, 그리퍼 자체의 스트로크 끝이 여전히 스톱 역할을 한다.

```
그리퍼 완전 닫힘 위치 = 갭 33.5 mm  ← 기구 스트로크 끝, 이보다 더 못 닫힘
따라서 35 mm 큐브의 최대 압착량 = 1.5 mm 로 물리적으로 제한
```

폼이 무르면 조가 스트로크 끝까지 닫히고 **초과 힘은 그리퍼 내부가 받는다.**
90 N 이 그대로 폼을 짓이기는 상황은 아니다.

→ 벤치 실험에서 볼 것은 오히려 반대쪽: **1.5 mm 압착만으로 큐브가 안 미끄러지는지.**
폼 몇십 그램을 드는 데 필요한 마찰력은 1 N 미만이라 문제없을 가능성이 높지만 실측 필요.

### 4.8 SMC 배포 CAD 의 신뢰 범위 — 핑거 PETG 선출력은 "필수" 가 아니라 "보험"

`cad/1/*.stp` · `cad/2/*.dxf` 는 MISUMI(PARTcommunity) 의 **SMC 공식 배포 파일**이다. 추정값이 아니다.
핑거의 체결 치수는 **두 파일에서 독립적으로 교차 확인**됐다.

| 치수 | STEP | DXF | |
|---|---|---|---|
| M4 위치 | Ø3.242 원통 @ 6.7 / 32.7 | Ø3.24 원 @ y = 6.7 / 32.7 | ✅ |
| M4 폭방향 | ±10 | x = 357.47 / 377.47 (= ±10) | ✅ |
| M4 탭 깊이 | — | `8xM4x0.7 thread depth 4` | ✅ |
| 블록 길이 39.40 | (단순화로 확인 불가) | 6.7 + 32.7, 전장 142.8 | ✅ |
| 측면 M5 | Ø4.134 @ Z = ±61 | 스팬 122 | ✅ |
| 배면 M5 | Ø4.134 @ Z = ±18, ±54 | `4xM5x0.8 thread depth 12` | ✅ |

**핑거가 볼트로 붙느냐를 결정하는 M4 위치는 두 소스에서 동일하다. 신뢰도 높음.**

다만 **받은 STEP 은 간이 모델**이라는 것도 이번에 확인됐다.

```
STEP bbox 전장 142.00   vs   DXF 도형 전장 142.8 (= 39.4 + 64 + 39.4)
→ STEP 이 블록 끝단을 생략
다월 Ø4 : STEP 은 −65.5 / −64.5 / +65.0 비대칭 3개(일부 필렛), DXF 도형은 ±65.0
→ 정정 이력 #5 (다월 위치 오류) 가 바로 여기서 나왔다
```

**판단**

| 상황 | 권고 |
|---|---|
| 프린터 사용 가능 | PETG 선출력 (반나절 · 재료비 수백 원). 알루미늄 리드타임 몇 주 대비 보험이 싸다 |
| 프린터가 없거나 번거로움 | **어댑터와 같이 발주해도 된다.** 체결 치수는 이중 확인됨 |

남은 실질 위험은 **립 상단 ↔ 몸체 밑면 여유 0.70 mm** 한 곳뿐이고,
여기서 걸려도 립 높이만 깎아내면 되는 수준이라 부품 폐기로 이어지지 않는다.


리머 4회를 피하므로 원안보다 오히려 싸다.

### 5.2 밸브 브래킷 — 재설계

```
136 × 4 × 28 평판  (플랜지 로컬 X ±68, Y 25~29, Z 18~46)
├ Ø5.5 관통 ×2  @ X=±61, Z=32          그리퍼 측면 M5 체결 (기존)
└ Ø3.4 관통 ×2  @ X=±11.3, Z=32        SY5120 체결 (신규)
  + Ø6.2 90° 카운터싱크 (그리퍼 쪽 면, 깊이 1.4)
```

**카운터싱크가 필요한 이유**: 브래킷은 그리퍼 측면에 밀착한다.
M3 볼트는 그리퍼 쪽에서 넣어 밸브로 들어가는데, 일반 육각소켓 머리(Ø5.5×3.0)면
**그리퍼와 브래킷 사이에 끼여 브래킷이 3 mm 뜬다.**
판이 4 mm 뿐이라 카운터보어(깊이 3)를 파면 1 mm 만 남아 못 쓴다.
→ 접시머리 + 90° 카운터싱크(1.4 mm)면 판이 2.6 mm 남아 충분하고 머리는 면일치.

STEP·STL 을 **플랜지 로컬 좌표로 통일**해 재생성했다 (이전엔 둘의 좌표계가 달랐음).
질량 11.3 g → **19 g (솔리드 기준)**.

### 스피드컨트롤러 — 품번 정정 및 가격

```

   →   AS1201F-M5-04  (SMC · 엘보 · 메터아웃 · M5×0.8 · Ø4 튜브 · 0.1~1 MPa)
```

| 유통처 | 개당 | 2개 |
|---|---|---|
| RS Korea | ₩16,394 | ₩32,800 |
| Automation Distribution (미국) | $7.35 | ≈ ₩20,000 |

**역할**: 니들밸브 + 체크밸브. 배기 쪽만 조여 조의 **닫힘 속도**를 낮춘다.
파지력은 레귤레이터(압력)가, 속도는 스피드컨트롤러(유량)가 정한다 — **독립된 두 손잡이**.

**없으면 안 되는 이유**: 조절 없이 닫으면 편측 32 mm 를 수십 ms 에 이동(조 속도 ≈ 1 m/s).
폼 큐브는 몇십 그램이고 정책 위치 오차가 mm 단위라 **한쪽 조가 먼저 닿아 큐브를 옆으로 쳐낸다.**
MHF2 는 최대 60 c.p.m.(초당 1회) 이라 늦춰도 과제에 손해가 없다.
권장 조합: 레귤레이터 0.2~0.3 MPa + 스피드컨트롤러.

> 09-03 검토는 **유지전류만** 봤다. 돌입은 42 mA 로 한계에 근접한다.
> 매뉴얼이 "전류 제한 없음 — 초과 시 영구 손상"이라 경고한 포트이므로,
> 불안하면 DO 로 소형 릴레이/MOSFET 을 구동하고 밸브는 별도 24 V 에서 먹인다.

## 10. 조립 순서 (M6 머리가 그리퍼에 덮이므로 순서 강제)

```
1. 어댑터 → 로봇 플랜지
   스피곳을 플랜지 보어에 먼저 안착 → M6×10 ×4, 그리퍼 쪽 카운터보어에서, 대각선 균등, 9 N·m
   ※ 9 N·m 초과 금지 — 로봇 쪽 암나사가 상하면 부품보다 비싸다

2. 다월 압입
   Ø4 H7 (깊이 6) ← ISO 2338 Ø4 m6 × 8 → 돌출 2 mm (재면서 압입)
   ※ 벽 두께 3 mm — 천천히

3. 그리퍼 → 어댑터
   M5×20 ×2, 로봇 쪽 면에서 (반경 54, 좁은 공간 — 볼 엔드 렌치)

4. 핑거 → 블록
   M4×6 ×8, 아래에서, 2 N·m. 립을 블록 바깥면에 밀착. 좌우 대칭으로 조임
   조인 뒤 조 면 간격 33.5 실측

5. 브래킷 → 그리퍼 측면
   밸브(+Y) M5×8 ×2  /  손목캠(−Y) 은 아직 부착 안 함
   ※ 탭 5.5 mm — M5×8 보다 긴 볼트 금지

6. 밸브 → 브래킷
   M3×6 접시머리 ×2, 그리퍼 쪽에서, 0.8 N·m

7. 배관
   밸브 A → 「S」(닫힘) / B → 「O」(열림)   ※ 정전 시 열려서 큐브를 놓도록
   ※ 스피드컨트롤러 없이는 배관하지 말 것
   ※ 공급 호스 마지막 구간은 J6 축과 동축 (어댑터 Ø20 보어 통과)

8. 컨트롤러
   Tool Weight 1.22 kg / 무게중심 (−0.8, 3.6, 25.1) / J6 소프트리밋 ±180° / TCP 83 재실측
```
