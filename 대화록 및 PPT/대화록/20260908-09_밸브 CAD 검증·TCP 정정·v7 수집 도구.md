## 2. 트러블슈팅 ① — 「22.6 이 틀렸다」 오판

CAD 에 실재하는 유일한 체결용 구멍이 대각 ±18/±5.8 (=36×11.6) 이라, 이걸 브래킷 체결 구멍으로 오인하고
**「발주서의 22.6 은 카탈로그 기록값인데 실제와 다르다, 브래킷 Ø3.4 @X=±11.3 을 (+18,+5.8)/(−18,−5.8) 로 옮겨야 한다」** 고 보고했다.

사용자 「다시 뽑아줘」 → 좌표를 고치기 **전에** SMC 카탈로그 PDF 를 받아 p.7 을 600 dpi 로 렌더해 읽었다.
`22.6 / 2-M3 x 0.5 depth 3.5 / (For mounting bracket)` 이 그대로 있었다. 대각은 `36 / 2-ø3.2 / (For manifold mounting)`.

→ **브래킷 좌표 원래 맞음. 파일 미변경.** 잘못된 좌표로 재생성했으면 못 쓰는 부품이 될 뻔했다.
09-07 §8 미확인 #1 `22.6 카탈로그 기록값` 이 **원도면 직접 확인**으로 닫혔다. 탭 깊이 3.5 → M3×6 (물림 2.0) 선정도 유효.

교훈: 모델에 없는 피처를 「없다」고 판단했다. CADENAS 는 작은 탭을 생략한다. 치수 근거는 카탈로그 원도면.

## 7. M3 면 논리 확정 · 스페이서 · 트러블슈팅 ② (9/9)

**옆면 확정 (사진 불필요)** — 좁은 면 2개는 포트가 점유: A/B 면은 Ø14.8 보스가 X 0.7~15.5, P/EA/EB 면은 EA 가 X −18.45~−8.75.
M3 를 ±11.3 에 둘 자리가 없다. 포트면으로는 붙일 수 없으니 **넓은 옆면(90.8×33)이 유일.** 좁은 면 접합(B)은 자동 배제.

→ 밸브 높이 33 이 Z, M3 Z=32 → 하단 포트면 Z≈15.5 (M3 높이 중앙/16.7/16.3 어느 가정이든 ±0.4). §4 의 간섭이 성립.
**대책 검토**: M3 를 Z 로 올리기 ✗(피팅이 여전히 어댑터를 향함) · 어댑터 모서리 따내기 ✗(절삭 발주 지연) · 엘보 △ · **스페이서(+Y) ✓ 유일한 완전 해결, 비용 0.**

스페이서 6 mm: 접합면 Y 29→35, 포트 중심 43.55. Ø14 피팅 안쪽 끝 36.55 (+1.55) · 소음기 Ø13 37.05 (+2.05).
나사 M3×6 → **M3×12** (통과 10, 물림 2.0, ×14 는 4.0>3.5 바닥). 26.19 g. 조립체 겹침 0. `make_bracket_v3.py`.

**트러블슈팅 ②** — 「브래킷 M5 Z=32 vs 그리퍼 측면 탭 Z=36, 4 mm 어긋남」 을 제기했다가 검증:
```
adapter_m1013_mhf2.step  자체좌표: Ø11 카운터보어 Z 0~7.5 (그리퍼 쪽 면 Z=0) · Ø31.5 스피곳 Z 12~16
tool_assembly_flangelocal.stl 정본: 스피곳 −4~0 · 판 0~12 · 그리퍼 접합면 Z=12    Z_asm = 12 − Z_step
```
그리퍼 로컬 Y=−20 측면 탭 → 플랜지 Z = 12+20 = **32** = 브래킷. 09-07 「조인트 5종 일치」 맞았다.
같은 착오로 「어댑터 상면 Z=16, 축방향 여유 −0.5」 도 틀림 → Z=12, +3.5. **스페이서 결론은 Y 방향이라 불변.**
매핑 검산: 그리퍼 배면 Ø4 다월 (0,−3.3,±65.0/−65.5·−64.5 장공) ↔ 어댑터 ±65 · 조 블록 밑면 Y=−33 + 38 = 플랜지 83 (STL 최대) 이 되려면 접합면 12.
