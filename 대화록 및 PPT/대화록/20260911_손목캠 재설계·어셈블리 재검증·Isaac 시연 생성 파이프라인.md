## 7. Isaac 시연 생성 파이프라인 (사용자 ①안)

### 7.1 학습 모델의 정체 (사용자 스크린샷 기억 요청)
OMX→M1013 변환은 학습이 아니라 기하(FK→EE→IK). 학습 = **ACT**(100k, 8/20; 입력 손목캠+정면캠+관절, 출력 관절 100프레임 청크). 추론은 닫힌 루프. v6 영상은 OMX 리그 것 → 도메인 갭. 현 정책 `/root/train_m1013_act_v6_tcp0725` (chunk 100, n_action_steps 100, resnet18, lr 1e-5, batch 8).

### 7.2 방식 3안
① Isaac 시연 대량 생성 → ACT (선택; 09-09 연구방향의 최유력 대안, 큐브 yaw 무작위화로 OMX yaw 결손 직접 메움) / ② RL Isaac Lab (픽셀 RL 수십~수백 GPU시간, 일정 불가) / ③ 비주얼 서보 (주제 무관). weld = 닫힘 순간 큐브를 플랜지에 운동학 고정; 생성엔 weld, 평가엔 기하 판정.

### 7.3 규약 확인
- v6 그리퍼: 열림 0.69, 닫힘 −0.02, 임계 0.459, 전이 ~5 프레임 · 파지 시 플랜지 x축 yaw 158.8°±7.4°, 수직 이탈 중앙값 9°(최대 31°) · 시작 관절 159개 저장 `sim_out/v6_start_q.npy`
- 집는 TCP x 0.706~0.908, y −0.325~−0.200 (20×12 cm) · 놓는 x 0.684~0.877, y −0.278~0.042 · 평균 480 프레임(16 s)
- 영상: h264 yuv420p 640×480 30fps (v5 ffprobe, 컨테이너 ffmpeg 로 파이프) · 메타 LeRobot v2.1 (info/episodes/tasks/episodes_stats, 이미지 stats (3,1,1))

### 7.4 `isaac_expert.py` / `gen_isaac_demos.py`
- 웨이포인트: 시작 → 큐브 위 6~11 cm → 하강 → [닫힘 0.45 s] → 들기 → 놓을 곳 위 → 하강 → [열림] → 후퇴. min-jerk + slerp, 매 프레임 `kin.solve` (실패·Δq>6° 폐기). 파지 R: z 수직, x yaw = 큐브 yaw 의 90° 배수 중 158.8° 최근접
- 사람 흉내: 손목 기울기 N(0,6°), 웨이포인트 지터 ±1 cm/±3 mm, 저주파 흔들림 ≤4 mm, 속도 ×0.85~1.3, 그리퍼 5프레임 램프
- DR: sun 700~2000·방향, dome 150~600, 상판 색, 큐브 색조, 손목캠 ±3 mm/±2°, 정면캠 ±1 cm
