## 1. TX90 — v6 (joint 출력) 모델 구축 완료

**배경**: EE pose 출력 모델(v5)은 실행 시 매 청크 IK 번역이 필요해 실시간성 보장이 어려움 (worst-case 지연 상한 없음, 특이점 근처 해 실패·손목 표류 실측). 디코더가 관절값을 직접 출력하도록 전환.

**데이터셋 v6 변환** (오프라인 IK, 실기 시연 0개로 joint 라벨 확보):

- 시연 159 에피소드 전체를 EE pose → joint 로 일괄 변환 (**159/159 성공**)
- 변환 규약: 작업대 오프셋 (−0.20, +0.15)m · 궤적 평활(7프레임) · 앵커 6Hz IK 체인 + 30Hz 관절 보간 · state = action[t−1] · 그리디 실패 시 DP 전역 탐색 폴백
- 트러블슈팅: 30Hz 전 프레임 IK의 손목 self-motion 드리프트(j4가 −265°까지 감김)·KDL 특이점 스톨·OMX 측정 노이즈 3종 원인 규명 → 알고리즘 6종 비교 실험 후 최종 규약 확정
- 오프셋 28종 × 159 에피소드 전수 스윕으로 작업 위치 재결정 → **실물 테이프도 (x−20cm, y+15cm) 위치로 이동 필요**
- 검증 4종 통과: 프레임 간 점프 최대 16.2° / FK 역검증 위치 ≤5.1mm / 브랜치 일관성 / 다봉성 kNN 0/4,770

**학습·평가**:

- ACT 100,000 스텝 (2.9시간), 최종 loss 0.052
- open-loop 관절오차 평균 0.93~1.55° (중앙값 0.4~0.6°), 그리퍼 개폐 일치율 96.8~99.2%
- RViz 재생: 예측 관절 궤적 직접 발행 — **IK 호출 0회**, v5에서 관찰되던 4번 축 공회전(특이점 표류) 완전 소멸

## 2. 두산 M1013 — VLA 지원 여부 확인

**결론**: M1013은 VLA 실시간 제어를 지원하며, 축 수가 다름에도 OMX→M1013 전이학습 가능함을 확인.

- **핵심**: 두산이 실시간 외부 제어 API를 공식 제공 (ROS2 servo 방식 + RT UDP 최대 1kHz) → VLA가 생성하는 action chunk의 **실시간 스트리밍 가능**
- **TX90 대비**: 산업용 motion-queue라 실시간이 막혔던 TX90과 달리, M1013은 실시간 스트리밍이 **기본 지원**되어 제약 해소
- **축 차이 및 전이학습**: OMX(4축)와 M1013(6축)의 자유도가 다르나, action space를 관절(joint)이 아닌 EE(엔드이펙터) delta-pose 기반으로 학습하면 축 수 불일치를 역기구학이 흡수하여 전이 가능. 데이터는 협동로봇 **Direct Teaching으로 수집 가능**
- **확인 필요**: 실기 유닛 컨트롤러 펌웨어 버전(2.12 이상)만 점검하면 됨

## 3. 시사점 — 두 플랫폼의 역할 분담 (판단 필요)

| | TX90 (산업용) | M1013 (협동) |
|---|---|---|
| 실시간 스트리밍 | CS9 velocity 확장 필요 (유상, 견적 미확정) | 기본 지원 (RT UDP 1kHz) |
| 데이터 수집 | 스크립트 시연 (외부 제어 개통 후) | Direct Teaching으로 즉시 가능 |
| 현재 자산 | v5·v6 모델 + 전체 변환 파이프라인 완성 | 미착수 |

- M1013이 열리면 **반응형(실시간) VLA 실기 검증 경로가 크게 단순**해짐 — TX90의 최대 관문(CS9 확장)을 우회
- TX90 트랙은 "산업용 컨트롤러 제약 하의 VLA 배포"라는 독자적 가치 유지 — 두 트랙 병행 여부는 M1013 펌웨어 확인 후 결정 제안
- 참고: v6에서 확립한 오프라인 IK 변환·검증 파이프라인(브랜치 일관성, kNN 검사 등)은 M1013 EE delta-pose 노선에서도 재사용 가능
