## 3. STEP 3 — Isaac 물리 검증 · 트러블슈팅

- 씬 직접 구성 (로봇 + 테이블 + 35mm 큐브 + LEHR 근사 그리퍼). 기하 발견: v5 '테이블 높이' = 상판이 아닌 파지 기준점 높이, 큐브 실측 35mm (기존 6cm 추정 오류 정정)
- **35mm 파지 실패 12회 트러블슈팅**: 갭 실측·핑거 궤적 기록·기하 분석으로 원인 규명 — 접근 이동 방향이 그리퍼 개구와 수직(내적 0.13) → 패들이 큐브를 쓸어냄 (실물 폼 큐브는 눌리며 팝인 — 강체 sim이 재현 불가)
- **해결 = 손목 45° 보정**: OMX 접근축 45°를 어태치먼트(HW)가 아닌 손목 IK 목표(SW)에서 상쇄 → 일자 장착 + 수직 하강 접근 + 특이점 탈출을 동시 달성. 소프트바디(FEM) 불채택. GT 물리재생 8ep 중 **6/8 성공** (오차 2.1~10.8mm)

## 6. 리스크·확인 필요 사항

- TCP 0.12m은 잠정값 — LEHR 실물 실측 후 상수 갱신 → 재변환(1분) + 재학습(~3h) 필요
- 시각 도메인 갭: 학습 영상은 OMX 팔 — closed-loop에서 실측 후 대응 결정 (co-training A/B / v7 이어학습)
- 강체 sim의 한계: 실물 어태치먼트 접촉면은 연질(TPU/폼) 권장 — 강체 팁은 동일 실패 위험
- 실물 배치가 sim 가정(상판 +0.432m, 사각형 0.46~0.70m)과 다르면 실측 후 오프셋 갱신 (재변환 1분)
