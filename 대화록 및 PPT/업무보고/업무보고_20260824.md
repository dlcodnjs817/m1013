## 3. 방법 선택 — 실측 역산 + 후보 스윕 (수동 좌표하강)

- **채택**: 원본 픽셀에서 초기값 역산(주사위 88px → 거리 25~30cm, 웹캠 FOV 통념으로 범위 한정) → Isaac 1회 부팅에 후보 3~4개 동시 렌더 → 주사위 화면 좌표(%)로 정량 채점 → 다음 후보 설계. **3라운드에 수렴**
- Isaac 부팅이 회당 ~1분이라 '1부팅 = 1라운드'로 반복 단위를 설계
- **기각한 대안**: PnP·체커보드(원본에 타깃 없음 + 로봇 자체가 다름 → 정확한 해가 존재하지 않는 문제) / 미분가능 렌더링 최적화(씬 내용이 달라 픽셀 손실 무의미, 7개 파라미터에 과한 도구) / Isaac GUI 수동 조작(재현성·정량 기록 없음, FOV 조정 불가)
- 판단 기준: 정답 구도가 애초에 없는 문제에서는 사람이 판단 루프에 남되, 렌더 배치·채점·기록을 자동화해 반복 비용을 줄이는 절충이 가장 빠르고 재현 가능

## 4. 정면캠 — 3라운드 수렴

- **R1 (A~D)**: 너무 멀어 상판 옆면·바닥까지 노출 → 원본은 표면을 스치듯 봄 → x 2.2 → 1.2~1.4m
- **R2 (E~H)**: 구도는 맞았으나 배경(파란 격자 바닥)·테이블색(갈색)이 실물(흰 벽·회색)과 상이 → 씬 보정(도메인 갭 직접 감소)
- **R3 (F1~F3)**: 흰 벽 + 회색 테이블로 **F1 확정**
- 정량 채점(주사위 화면 가로 위치): 원본 파랑 19% · 노랑 84% → F1 파랑 29% · 노랑 79% (후보 중 최근접)
- 확정값: `pos (1.20, −0.25, 0.46)` · `look_at (0.45, −0.15, 0.52)` · `focal 15mm (HFOV 69.9°)` · 640×480
- **트러블슈팅 ③**: 1차 프로브 전멸(zero-norm quaternion) — look-at→쿼터니언 단순 공식은 카메라가 정확히 −x 를 볼 때 180° 회전 → w=0 → 0-나눗셈. `scipy Rotation.from_matrix` 로 교체(기존 `capture_m1013.py` 는 카메라가 비스듬해 우연히 안 걸렸던 것)

## 5. 손목캠 — 거동 분석 → 기하 역산 → 실증 보정

실물 프레임(ep80 시간축)에서 읽어낸 3가지가 역산 근거:

1. 하향 시점 + 이미지 위 = 접근 방향 (주사위가 위에서 진입)
2. 파지점이 화면 하단 중앙 → 카메라가 파지축에서 접근 방향으로 ~6.5cm 오프셋 장착
3. 파지 시 주사위 폭 ~250px → 카메라-주사위 6~10cm

sim 이식: 접근 방향 = 플랜지 로컬 `(−0.655, −0.755, 0)`(flange0 궤적 역산), 전방 = 로컬 +z(손목 45° 보정 덕에 파지 시 세계 수직 하향), 부착 = `link_6` 자식 prim → USD 변환 상속으로 물리 자동 추종(조인트 불필요).
M1013 스케일 제약: 그리퍼가 길어(플랜지→팁 0.21m) 실물만큼 크게 볼 수 없어 FOV 60°로 절충(실물 대비 약 70% 크기).

- **트러블슈팅 ④ — 이미지 롤 90° 어긋남**: 오프셋을 '이미지 위'로 줬는데 큐브가 순수 '오른쪽'으로 밀림. 기하로 모순 증명(up 방향 오프셋의 화면 변위는 right 성분 = o·(f×up) = 0 이어야 함) → 실효 이미지-up 이 지정 up 과 90° 어긋남. **해석 포기 → 실증 캘리브레이션**: up 인자 90° 단위 4방향 스윕으로 'up 인자 +90° = 화면 +90° 회전' 관계와 오차각(215° vs 목표 270°) 실측 → R3 에서 +55°(R145)가 하단 중앙 적중
- **확정 V3**: `local_pos (−0.039, −0.045, 0.05)` · forward = 로컬 +z · `up_arg (−0.970, −0.243, 0)` · `focal 18mm (HFOV 60.3°)`. 파지 컷 큐브 중심 (0.38, 0.86)·폭 170px vs 실물 (~0.33, ~0.9)·~250px
- `up_arg` 는 **실증 보정값** — JSON 에 경고 주석과 함께 저장, 재유도 금지·그대로 사용
- **트러블슈팅 ⑤**: 파지 컷에 실물에 없는 테이블 모서리·파란 바닥 노출(M1013 파지점이 테이블 구석에서 13~14cm) → **렌더용 테이블만** (0.49,0.60) → (0.85,1.10)m 확대, 상판 z 동일. 물리 검증 씬은 원치수 유지. pick/place 는 테이블 중앙부라 지지면 변화 없어 물리에 무해
