## 1. 오늘 수행 업무 — 데이터 결함 수정 · 재학습 · RViz 재생 검증

### 오전 — rx·rz의 ±π 경계 ~2π 점프 결함 발견 → mod 2π 재매핑으로 v5 데이터셋 생성
- v4 10k 체크포인트 평가에서 자세 오차 90퍼센타일 87°로 비정상 → 원인 추적.
- 원인: rx·rz가 [−π, π] 저장인데 실제 자세(그리퍼 수직 아래)가 ±π 근처에 몰려
  프레임 간 ~2π 점프 발생 (rz 159/159 에피소드 437회, rx 106/159 289회).
  MSE 학습하는 ACT가 불연속을 평균 내 ±π 근처에서 −1.6 같은 중간값을 예측.
- 수정: rx·rz를 mod 2π로 [0, 2π) 재매핑 (`fix_euler_wrap.py`).
  데이터가 π 중심이라 0 근처 프레임이 없어(|rz|<1 = 0개) 재매핑 후 점프 0회,
  프레임 간 최대 변화 0.119 rad 실측.
- 대안(6D sin/cos, 쿼터니언 전면 교체)은 스키마·실행측 수정 범위가 커서 배제 —
  데이터 분포상 단순 재매핑으로 충분함을 실측 확인.
- 결과: `dlcodnjs/tx90_act_pick_and_place_v5_ee` (159 ep, 76,345 프레임,
  통계 재계산, lerobot 로드 검증 완료).
