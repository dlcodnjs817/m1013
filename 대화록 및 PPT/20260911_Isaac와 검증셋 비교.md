- **공통점**: 둘 다 ACT, 100k 스텝, 배치 8, 같은 lerobot 설정.

## 시연 생성 (`gen_isaac_demos.py`, 지금 돌아가는 것)

**뭘 하나:** Isaac 시뮬레이터 안에서 "정답 동작"을 1000번 만들어 녹화합니다.

한 에피소드(6~7초)에 일어나는 일:
1. 큐브를 상판 위 무작위 위치·회전에 놓는다
2. **스크립트 전문가**가 큐브 위치를 **정확히 알고 있으니**(시뮬이니까 좌표를 그냥 읽음) IK로 "접근 → 내려가기 → 잡기 → 들기 → 옮기기 → 놓기" 관절 궤적을 계산한다. 사람처럼 보이게 손목 기울기·흔들림·지터를 약간 섞는다
3. 로봇이 그 궤적대로 움직이는 동안 손목캠·정면캠 **영상을 렌더**하고, 매 프레임의 **관절값**을 기록한다
4. `episode_000123.parquet`(관절) + `episode_000123.mp4`(카메라 2개) 로 저장 — v6와 똑같은 형식

여기엔 **신경망이 전혀 없습니다.** 순수 기하(IK)와 렌더링뿐. 그래서 GPU는 렌더에만 쓰고 결과는 "이 화면이 보일 때 관절은 이렇게 움직여야 한다"는 (영상, 관절) 쌍 1000개 × 수백 프레임.

**핵심 트릭:** 전문가는 큐브 좌표를 치트로 읽지만, 저장되는 데이터에는 큐브 좌표가 **없습니다.** 영상과 관절만 있습니다.

## 학습 (`lerobot.scripts.train`, 생성 끝나면 자동 시작)

**뭘 하나:** 위 데이터를 보고 ACT 신경망이 "영상 → 관절 궤적"을 흉내내도록 100k 스텝 훈련합니다.

한 스텝에 일어나는 일:
1. 1000개 에피소드 중 랜덤 프레임 8개를 뽑는다
2. 각 프레임의 **두 카메라 이미지 + 현재 관절**을 신경망에 넣는다
3. 신경망이 "앞으로 100프레임 관절값"을 예측한다
4. 실제 기록된 100프레임과 비교해서 틀린 만큼 가중치를 고친다 (loss 감소)

100k 번 반복하면 신경망은 **큐브 좌표를 모른 채 화면만 보고** 큐브가 어디 있는지 → 어떻게 팔을 움직일지를 스스로 익히게 됩니다. 전문가는 좌표를 치트했지만, 학생은 눈으로 배워야 하는 거죠.

## ① split 학습 — 이어짐 (수동 재개)

- 에피소드마다 parquet + mp4를 **바로 디스크에 쓰니까** 끝난 에피소드는 안 잃음.
