## 발주 ② 핑거 어태치먼트 — **절삭 (좌·우 1쌍)**

**첨부**: `핑거/finger_right.step`, `핑거/finger_left.step`

> **권장: 프린팅 시제품으로 조립 확인 후 발주.**
> `finger_right.stl` / `finger_left.stl` 을 먼저 출력해 그리퍼에 달아보고,
> 립 걸림·M4 정렬·닫힘 갭을 확인한 뒤 알루미늄으로 넘어가면 위험이 0이 됩니다.
> 형상은 CAD 실측 기반이라 그대로 가도 되지만, 프린팅은 반나절이면 끝납니다.

```
품명    : 공압 그리퍼 핑거 어태치먼트 (SMC MHF2-16D2 용)
재질    : AL6061-T6
수량    : 좌 1 EA + 우 1 EA (미러 형상, 총 2 EA)
질량    : 각 약 54.9 g (참고)

[주요 치수]  ※ 원점 = 그리퍼 중심선, 완전 닫힘 기준
   마운트 판     43 × 27 × t8
   위치결정 립   X 39.40 ~ 43.0, 판 위로 높이 4.0   ★X=39.40 공차 필수
   M4 관통       Φ4.5, X = 6.70 / 32.70, Y = ±10    ★위치 공차 필수
                 + Φ7.5 카운터보어 깊이 4.5 (판 아래쪽에서)
   조            X 16.75 ~ 30, 폭 30, 블록 밑면에서 38 돌출
   TPU 라이너 홈  조 안쪽면에 1 mm 깊이 (라이너가 면일치 — 갭에 영향 없음)

[공차]
   립 내측면 X = 39.40 ± 0.10   ← 닫힘 갭을 직접 결정
   M4 홀 위치  ± 0.10
   조 안쪽면 X = 16.75 ± 0.10   ← 닫힘 갭 33.5 를 직접 결정
   기타 자유공차

[기타]
   · 전 모서리 디버링
   · 립 내측면은 그리퍼 블록 바깥면에 밀착 — 버 없을 것
```

**설계 근거**: 그리퍼 핑거 블록 길이 39.40 / 몸체 아래 돌출 4.70 / 어태치먼트 나사 8-M4 DP4
— 전부 SMC 실물 STEP 실측값.
닫힘 갭 33.5 mm = 35 mm 폼 큐브를 1.5 mm 압착.
**금속 조 면이 갭을 결정하고 TPU 라이너는 마찰만 담당**한다 (홈 1 mm · 면일치).
좌우 조는 서로 닿지 않으므로 하드 스톱은 없고, 압착량은 공급 압력으로 조절한다 (0.1 MPa ≈ 18 N).

## 조립 순서 (중요 — 순서 틀리면 볼트에 접근 못 함)

```
1. 어댑터 → 로봇 플랜지
   M6×10 ×4 (와셔 없음), 그리퍼 쪽 카운터보어에서 체결, 9 N·m
   나사 물림 5.5 mm / 머리 1.5 mm 잠김

2. 그리퍼 → 어댑터
   Φ4 다월 2개 삽입 후, M5×20 ×2 를 로봇 쪽 면에서 체결
   ※ M6 머리는 그리퍼에 덮이므로 1번을 반드시 먼저

3. 핑거 → 그리퍼 블록
   립을 블록 바깥면에 밀착시키고 M4×6 ×8, 아래에서 체결 (2 N·m — 과토크 시 그리퍼 암나사 손상)

4. 브래킷 → 그리퍼 측면
   밸브 브래킷 (+y), 손목캠 브래킷 (−y) — M5×8 각 2개

5. 배관: 밸브 A → 그리퍼 「S」(닫힘) / B → 「O」(열림)
   ※ 정전·비상정지 시 열려서 큐브를 놓도록 (안전)
   ※ 공급 호스 마지막 구간은 J6 축과 동축 정렬 (어댑터 Φ20 보어 통과)
```
